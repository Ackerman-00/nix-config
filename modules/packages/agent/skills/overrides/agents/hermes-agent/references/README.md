# Legacy reference material

The files in this directory document Hermes Agent, the framework this skill
previously covered. They are kept for comparison and migration notes only.

`SKILL.md` is the authoritative guide for OpenCode v2's agent system:
`~/.config/opencode/agents/*.md`, the `agents` map in `opencode.json`,
`default_agent`, and the `{ action, resource, effect }` permission rules.

Read the SKILL.md first. Use these files only when the user asks specifically
about a Hermes feature (profiles, skins, TUI widgets, desktop plugins, bot
mode, the Hermes gateway) and you need to describe what that feature was and
what the OpenCode equivalent is.
